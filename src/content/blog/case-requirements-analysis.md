## 🎯 Контекст проекта

Крупный региональный банк решил провести редизайн своего мобильного приложения. Основная проблема — устаревший интерфейс и низкий NPS (Net Promoter Score) среди пользователей. Моя задача заключалась в сборе и анализе требований для новой версии.

### Scope проекта

- Переработка основного флоу платежей
- Новый раздел "История операций" с фильтрами
- Интеграция с системой лояльности
- Push-уведомления о транзакциях

## 👥 Работа со стейкхолдерами

### Матрица стейкхолдеров

| Роль                | Интерес | Влияние | Стратегия               |
| :------------------ | :-----: | :-----: | :---------------------- |
| Product Owner       | Высокий | Высокое | Тесное взаимодействие   |
| UX-дизайнер         | Высокий | Среднее | Совместные воркшопы     |
| Backend-команда     | Средний | Высокое | Регулярные синки        |
| Служба безопасности | Низкий  | Высокое | Согласование требований |

### Методы сбора требований

1. **Интервью** с ключевыми стейкхолдерами (8 сессий)
2. **Анализ обратной связи** пользователей (500+ отзывов)
3. **Конкурентный анализ** (5 приложений-конкурентов)
4. **Наблюдение** за использованием текущей версии

## 📋 User Stories

### Epic: Платежи

```
US-001: Быстрый платёж по номеру телефона
Как пользователь приложения,
Я хочу переводить деньги по номеру телефона,
Чтобы не искать реквизиты получателя.

Критерии приёмки:
- Поиск получателя по номеру из контактов
- Отображение банка получателя
- Подтверждение через Face ID / Touch ID
- Сохранение в избранное
```

```
US-002: Шаблоны платежей
Как пользователь, который регулярно совершает одинаковые платежи,
Я хочу создавать и использовать шаблоны,
Чтобы экономить время на заполнении реквизитов.

Критерии приёмки:
- Создание шаблона из истории операций
- Редактирование названия шаблона
- Группировка шаблонов по категориям
```

- Просмотр истории

## 🎨 Прототипирование

Совместно с UX-дизайнером были созданы lo-fi прототипы в Figma:

### Ключевые экраны

1. **Главный экран** — баланс + быстрые действия
2. **Перевод** — 3-шаговый wizard
3. **История** — с фильтрами и поиском
4. **Детали операции** — чек + действия

### Результаты тестирования прототипа

Проведено **15 юзабилити-тестов** с представителями целевой аудитории:

- **87%** успешно завершили сценарий перевода
- **93%** оценили новый интерфейс как "понятный"
- Среднее время выполнения перевода сократилось с **2:30** до **0:45**
