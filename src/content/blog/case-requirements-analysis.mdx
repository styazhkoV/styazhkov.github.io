## Проблема

Региональный банк проводил редизайн мобильного приложения: устаревший UI и низкий NPS. Нужно было собрать и структурировать требования по платежам, истории операций и лояльности.

## Решение

Методы: интервью (8 сессий), анализ 500+ отзывов, конкурентный анализ, юзабилити-тесты прототипов.

Стек: UML Use Case, User Stories, Figma, Jira, Confluence, матрица трассировки.

  Client((Клиент))
  UC1([Авторизация])

  UC4([Шаблоны платежей])

  Client --> UC4`} />

## Результаты (KPI)

- **87%** успешно завершили сценарий перевода
- **93%** оценили интерфейс как понятный
- Среднее время перевода: **2:30 → 0:45**
- Документация: SRS 47 стр., 34 user stories
