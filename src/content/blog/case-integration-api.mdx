## Проблема

Устаревший модуль на **Oracle** не мог эффективно обмениваться данными с новым микросервисом через REST API. Нужны были real-time синхронизация, минимальная нагрузка на legacy и отказоустойчивые retry.

## Решение

Выбран паттерн **Change Data Capture (CDC)** с Oracle Streams. Спроектированы методы:

- `GET /api/v1/transaction/{id}`
- `POST /api/v1/transaction`

Стек: SQL, REST API, Swagger, логирование ошибок, exponential backoff.

## Результаты (KPI)

- **99.9%** uptime интеграционного слоя
- **&lt; 500ms** среднее время обработки
- **0** потерянных транзакций за 6 месяцев
